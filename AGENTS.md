# AGENTS.md — ARZ.dev Portfolio

## Project Overview
Premium portfolio for Rijuyan Ahmed (ARZ). Two-world architecture:
- **Architect** (`/`) — Professional identity: skills, projects, experience, ads showcase
- **Wanderer** (`/beyond`) — Personal identity: nature, life vision

## Tech Stack
- Next.js 14 (App Router) — strict-mode TypeScript
- React 18 + TypeScript (strict: true)
- Tailwind CSS 3
- Three.js (raw, used in HeroSection + AnimatedShaderBackground)
- Framer Motion (only animation lib used)
- Embla Carousel (powers LogoCarousel)
- Radix UI primitives (accordion, avatar, slot, tooltip)
- GSAP (used by LayeredText only)

## Dev Commands
```bash
npm run dev     # localhost:3000+
npm run build   # production build
npm run lint    # next lint
npx tsc --noEmit  # type-check
```

## Image / Asset Pipeline
- Originals in `public/**/*.png` and `*.jpg` are kept as backups (not deployed in the optimized path).
- Components reference `.webp` variants (~1.9 MB total) generated by `scripts/optimize_images.py`.
- Re-run after adding new images:
  ```bash
  uv run scripts/optimize_images.py
  ```
- Unsplash images for `/beyond` are self-hosted in `public/beyond/gallery/` and `public/beyond/vision/`. To re-fetch: `uv run scripts/fetch_unsplash.py`.
- `next.config.js` `remotePatterns` only allows `cdn.simpleicons.org`.

## Key Files

### Pages (App Router)
- `app/layout.tsx` — Fonts, full metadata (OG/Twitter), viewport export, `WorldProvider`
- `app/page.tsx` — Hero + dynamic-imported below-the-fold sections
- `app/beyond/page.tsx` — Wanderer world
- `app/loading.tsx` / `app/error.tsx` / `app/not-found.tsx` — UX boundaries
- `app/sitemap.ts` / `app/robots.ts` — SEO
- `app/opengraph-image.tsx` / `app/icon.tsx` — Edge-rendered OG image + favicon

### Sections (Architect)
- `HeroSection.tsx` — Three.js starfield + nebula + mountains. Disposes all GL resources, respects `prefers-reduced-motion`, debounced resize.
- `SkillsSection.tsx` — Radix accordion + OrbitingSkills + mobile horizontal scroll
- `ProjectsSection.tsx` — FeatureCarousel + CompactProjectCard with 3D tilt + parallax + border-trace
- `MetaAdsShowcase.tsx` — Animated count-up KPIs + stacked bar chart
- `ExperienceSection.tsx` — Timeline + certifications
- `WandererTransition.tsx` — Bridge to /beyond
- `ContactSection.tsx` — CTA + 4 social links + cosmic ambient

### Sections (Wanderer)
- `NatureHeroSection.tsx` — 3D parallax layers, rAF-throttled mouse parallax
- `SunsetGallerySection.tsx` — Scroll-zoom parallax (self-hosted)
- `LifeVisionSection.tsx` — Alternating image/text scroll reveals (self-hosted)
- `BeyondCTA.tsx` — CTA bridge back

### Layout
- `Navbar.tsx` — Fixed nav, scroll links, hamburger menu on mobile
- `BeyondNavbar.tsx` — Warm nav
- `Footer.tsx` — Copyright (year via `getCurrentYear()` to avoid hydration mismatch)
- `WorldToggle.tsx` — ARCHITECT/WANDERER router toggle (state via `WorldContext`)

### Lib
- `lib/WorldContext.tsx` — Routes /  ↔ /beyond syncing to a `world` state for components that want to react
- `lib/motion-utils.ts` — `prefersReducedMotion()`, `debounce()`
- `lib/hydration-utils.ts` — `SeededRandom`, `getCurrentYear()`
- `lib/utils.ts` — `cn()` (clsx + tailwind-merge)

### Hooks
- `hooks/use-tilt-3d.ts` — 3D card tilt motion values for project cards
